# An-lise-Explorat-ria-de-Vendas---E-Commerce
Análise exploratória de dados de vendas de e-commerce em Python (Pandas, NumPy, Matplotlib e Seaborn). O projeto gera dados fictícios para tratar, calcular o faturamento mensal, identificar os produtos mais vendidos e avaliar a receita por categoria e estado, transformando dados brutos em insights práticos para tomada de decisão no negócio.
